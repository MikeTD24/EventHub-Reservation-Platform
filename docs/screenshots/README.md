# Captures EventHub

Les images publiées dans le README principal doivent être prises sans barre d’adresse ni outils de développement, avec une largeur de fenêtre d’environ 1440 px.

Captures disponibles :

- `event-list.png` : agenda public et filtres.

Captures complémentaires prévues :

- `event-detail.png` : détail d’un événement et formulaire de réservation ;
- `admin-events.png` : statistiques et gestion des événements ;
- `admin-participants.png` : liste des réservations d’un événement.
